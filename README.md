# AI Chat Navigator

一款支持 Google Gemini 和豆包网页版的 Chrome / Edge 扩展。它会从当前对话中提取用户提问，生成可搜索的侧边目录，并支持跳转、高亮、重命名和收藏。扩展界面为英文。

## 功能

- 自动扫描 Gemini 对话里的用户提问，适配 `user-query`、`m-user-query` 等页面结构。
- 支持豆包的 `send_message` 标记和用户消息气泡结构，排除助手回复与侧栏内容，并识别文件名和图片消息。
- 通过侧边栏搜索提问，并平滑跳转到对应消息。
- 支持自定义导航标题和收藏。
- 标题与收藏保存在浏览器本地存储中，按站点、会话隔离；保留旧版本的 Gemini 数据。
- 自动更新新增提问、修改后的文本和页面内切换的会话。
- 豆包按消息 ID 累积索引：消息离开页面、被虚拟列表卸载后，仍可搜索、收藏和重命名；刷新页面后保留已索引提问。
- 点击 **Load full history** 自动滚动扫描当前对话，读取尚未加载的历史消息；扫描结束恢复阅读位置。可随时点击 **Stop**，或直接滚轮、触摸、翻页中断，已扫描结果会保留。
- 点击已卸载提问时，自动滚动重新加载并按消息 ID 定位；相同内容的多次提问分别记录。
- 面板收纳在 Shadow DOM 中，减少与页面样式冲突。
- 仅在 `gemini.google.com` 和豆包的 `/chat` 页面上运行，不读取其他网站。

## 安装（开发者模式）

1. 打开 Chrome 或 Edge 的扩展管理页。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目文件夹。
5. 打开或刷新 [Gemini](https://gemini.google.com/app) 或 [豆包](https://www.doubao.com/chat/) 对话页，点击页面右侧的 **Navigator** 按钮。

更新代码后，在扩展管理页点击扩展卡片上的重新加载按钮，再刷新对话页面。2.1.0 新增豆包站点权限，浏览器可能提示确认访问权限。

豆包首次打开长对话时，目录只包含已索引的部分。点击 **Load full history** 可补全当前对话的历史目录。单轮扫描最多持续两分钟，超时会保留部分结果并提示继续扫描；网络延迟可能导致暂时未读到更早消息，可在加载后再次扫描。扩展只索引你打开的当前对话，不批量读取其他聊天。

历史索引中的提问文本、收藏和标题都保存在浏览器本地，不发送到外部服务。豆包的地区或登录限制由网站决定。Gemini 仍按当前页面消息建立目录。

## 本地开发

此扩展运行时不需要构建步骤或第三方依赖。核心文件为 `manifest.json`、`src/content.js`、`src/history.js` 和 `src/style.css`。

开发检查：`npm ci` 后执行 `npm run check` 和 `npm test`。测试使用 jsdom 验证消息识别、搜索跳转、数据持久化、会话隔离、虚拟列表回收、历史分页、取消和超时，不替代真实网站验证。
